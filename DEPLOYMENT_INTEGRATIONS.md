# Integraciones de despliegue

La integración Git de Vercel de BuscoFácil está retirada. Los proyectos
facil-admin y buscofacil-web se desconectaron mediante la herramienta oficial.
El proyecto antiguo audio_ai_project ya no estaba conectado.

Los cambios de este repositorio no deben conectar ni crear proyectos en esa
plataforma. Los despliegues vigentes se gestionan por el flujo del servidor
propio. Sus archivos y workflows no se modifican en esta limpieza.

No confundir comentarios o estados antiguos de despliegue con una conexión
activa: la comprobación se hace leyendo la vinculación Git del proyecto.
